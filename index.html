FAQ

What exactly do I get?

A copy-in Claude Code setup: a permission allowlist, hooks, and skills, plus (tier-dependent) starters, a worked example, and launch/pricing/distribution playbooks.

What's the difference between the tiers?

Lite (free) = 2 hooks, 2 skills, the template. Standard = all 6 hooks + 7 skills. Pro = Standard + 2 starters + the worked example + launch assets.

Do I need to be an expert?

No. Follow the 15-minute setup doc. Defaults work; you trim to your stack.

Which stacks does it support?

Stack-agnostic. The format hook ships commands for JS/TS, Python, Go, Rust, and Java; starters are Next.js and Node CLI.

Will it break when Claude Code updates?

Config may need small tweaks over time. Updates within the v1.x line are included free.

Can I use it for client and commercial work?

Yes — unlimited projects, personal or commercial. You may not resell or redistribute the kit itself. One seat per developer.
