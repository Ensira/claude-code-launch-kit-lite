# Ship a SaaS — Lite

A short forcing function so you build instead of polishing.

## Phase 0 — Cut scope
One sentence: "X helps Y do Z." Delete every feature not required for the first user.

## Phase 1 — Skeleton
Auth + one protected page. `npm run dev` serves a logged-in page.

## Phase 2 — The one thing
Build only the core action. Hardcode the rest. You complete it end-to-end as a user.

> **Lite stops here.** Pro adds Phase 3 (Stripe money), Phase 4 (deploy/ship), and
> Phase 5 (one distribution channel) — each with a hard done-check — plus the
> `pricing-experiment` and `distribution-sprint` skills. See `../pro/`.
